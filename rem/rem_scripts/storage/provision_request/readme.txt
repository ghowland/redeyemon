./rem/rem_scripts/storage/provision_request, is like the storage/provision directory, accept for the next stage of volumes.

The storage/provision directory scripts specify how many volumes to create.

These storage/provision_request scripts specify how to request those volumes.

Examples:

- From the Cloud
- Local disk, no requesting needed and is automatatically Assigned
- Other (...?)


Obviously this was made to split cloud requested storage from on-machine storage, other uses may occur.
